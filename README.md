# 🚗 Исполнители — Робот-садовник

Образовательная среда для обучения основам программирования с учебным исполнителем "Робот".

## 📋 Описание

**Робот** — это машинка, которая ездит по полю и сажает цветы на грядках. Робот должен посадить цветы на всех грядках и вернуться на Базу для пополнения запасов.

### Элементы поля

| Элемент | Описание |
|---------|----------|
| 🟫 **Плитка** | Свободное место, по которому можно ездить |
| 🟤 **Грядка** | Место, где нужно посадить цветы |
| 🌸 **Клумба** | Грядка с посаженными цветами |
| 🧱 **Стена** | Препятствие, через которое нельзя проехать |
| 🅿️ **База** | Место, куда нужно вернуться |
| 🚗 **Робот** | Машинка-садовник |

## 🚀 Запуск

Откройте файл `index.html` в браузере или запустите локальный сервер:

```bash
cd executor
python3 -m http.server 8080
```

Затем откройте http://localhost:8080

## 📖 Структура программы

Программа **обязательно** должна иметь имя и быть заключена в фигурные скобки:

```
ИмяПрограммы
{
    команды;
}
```

## 📖 СКИ Робота (Система Команд Исполнителя)

| Команда | Описание |
|---------|----------|
| `направо;` | Повернуться на 90° вправо |
| `налево;` | Повернуться на 90° влево |
| `кругом;` | Развернуться на 180° |
| `вперед(n);` | Проехать на n клеток вперёд **(скобки обязательны!)** |
| `назад(n);` | Проехать на n клеток назад **(скобки обязательны!)** |
| `посади;` | Посадить цветы на грядке |

**Важно:**
- Команды `вперед` и `назад` требуют обязательный параметр в скобках
- Точка с запятой `;` в конце команды опциональна

### Ограничения

- Робот **не может** ходить по диагонали
- Робот **не может** проходить сквозь стенки
- Робот **не может** топтать цветы на клумбах
- Робот **не может** сажать цветы там, где нет грядки

## ⚠️ Типы ошибок

### 1. ❌ НЕ ПОНИМАЮ (синтаксические)
Появляются при ошибках в написании команд:

```
влево;          // Ошибка! Правильно: налево
вперет(3);      // Ошибка! Правильно: вперед(3)
направо(2);     // Ошибка! направо не принимает параметр
```

### 2. 🚫 НЕ МОГУ (отказы)
Появляются, когда робот не может выполнить команду:

- Попытка проехать сквозь стену
- Попытка проехать по клумбе (топтать цветы)
- Попытка посадить цветы там, где нет грядки
- Попытка посадить цветы там, где они уже есть

### 3. Логические ошибки
Робот понимает команды и выполняет их, но результат не тот, что ожидался. Такие ошибки нужно находить самостоятельно!

## 🔄 Циклы

### Цикл "повтори"

```
повтори N раз {
    команды
}
```

**Пример:**
```
повтори 4 раз {
    вперед(1);
    направо;
}
```

### Цикл "пока"

```
пока условие {
    команды
}
```

**Пример:**
```
пока свободно_впереди {
    вперед(1);
}
```

## ❓ Условия

### Оператор "если"

```
если условие {
    команды
}
```

или с веткой "иначе":

```
если условие {
    команды1
} иначе {
    команды2
}
```

### Доступные условия

| Условие | Описание |
|---------|----------|
| `стена_впереди` | Впереди стена |
| `стена_слева` | Слева стена |
| `стена_справа` | Справа стена |
| `стена_сзади` | Сзади стена |
| `свободно_впереди` | Впереди можно проехать |
| `свободно_слева` | Слева можно проехать |
| `свободно_справа` | Справа можно проехать |
| `свободно_сзади` | Сзади можно проехать |
| `на_грядке` | Робот стоит на грядке |
| `на_базе` | Робот стоит на базе |
| `клетка_закрашена` | На клетке уже посажены цветы |

### Отрицание

```
пока не на_базе {
    ...
}
```

## 📝 Примеры программ

### Простейшая программа (задача z1-3.maz)

```
ТриКлумбы
{
    вперед(3);
    посади;
    направо;
    вперед(2);
    налево;
    вперед(2);
    налево;
    вперед(1); посади;
    вперед(2); посади;
    вперед(1);
    налево;
    вперед(1);
}
```

### Засадить все грядки и вернуться на базу

```
пока не на_базе {
    если на_грядке {
        посади;
    }
    если свободно_впереди {
        вперед(1);
    } иначе {
        направо;
    }
}
```

### Проехать и вернуться

```
вперед(5);
кругом;
вперед(5);
```

## 📁 Формат файлов .maz

Загружайте лабиринты из файлов формата `.maz`:

| Символ | Значение |
|--------|----------|
| `.` | Свободная клетка (плитка) |
| `w` | Стена |
| `x` | Грядка |
| `0` | Начальная позиция робота |
| `b` | База |
