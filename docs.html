Справочник команд

От первой программы до циклов, функций и массивов. Русские и английские варианты команд можно использовать в одной программе.

01. Первая программа

Укажите имя программы, затем запишите команды внутри фигурных скобок. После команды ставьте точку с запятой. Скопируйте пример в редактор и нажмите «Выполнить». 

Приветствие
{
    выводстр "Привет, мир!";
}

Текст появится в консоли под редактором. Для вычислительных программ лабиринт не нужен. После имени программы можно поставить пустые скобки: Приветствие().

Комментарии // до конца строки и /* на нескольких строках */ не выполняются.

02. Команды Робота

Робот перемещается по клеткам и сажает цветы на грядках. Стены и засаженные клумбы закрывают путь. Цель задачи — засадить все грядки и закончить программу на базе.

Команда Английский вариант Действие
вперед(n); forward(n); Пройти n клеток в направлении взгляда.
назад(n); backward(n); Пройти n клеток назад, сохранив направление взгляда.
налево; left; Повернуться на 90° влево.
направо; right; Повернуться на 90° вправо.
кругом; around; Развернуться на 180°.
посади; paint; Посадить цветы на текущей незасаженной грядке.

Число шагов должно быть целым и неотрицательным. Можно передать выражение: вперед(2 + n);. У команд без аргументов допустимы пустые скобки: направо();.

Дополнительные названия команд

вперёд означает вперед, back — назад, влево и вправо — поворот без аргументов, turnaround — кругом. Названия посадить, закрасить и закрась без аргументов означают посади.

Пример с готовым лабиринтом

Сохраните эти три строки в файл example.maz и загрузите его кнопкой 📥 над полем. Робот смотрит вправо, рядом находятся грядка и база. 

wwwww
w2xbw
wwwww
Посадка
{
    вперед(1);
    посади;
    вперед(1);
}

03. Датчики и условия

Датчик возвращает истина или ложь. Направления «впереди», «сзади», «слева» и «справа» отсчитываются от направления взгляда Робота.

Датчики Что проверяют
впереди_стена, сзади_стена, слева_стена, справа_стена Есть ли рядом стена или граница поля.
впереди_клумба, сзади_клумба, слева_клумба, справа_клумба Есть ли рядом уже засаженная клумба.
впереди_свободно, сзади_свободно, слева_свободно, справа_свободно Можно ли перейти в соседнюю клетку: там нет стены и засаженной клумбы.
грядка Стоит ли Робот на грядке, где ещё нет цветов.
база Стоит ли Робот на базе.

После посади датчик грядка в этой клетке становится ложным. Условия можно объединять: впереди_свободно и не база.

Дополнительные названия датчиков

Допустим обратный порядок слов: стена_впереди, клумба_справа, свободно_слева — и так для каждой стороны. Датчик грядка также называется на_грядке, на_цели или цель; база — на_базе. Дополнительный датчик клетка_закрашена проверяет цветы в текущей клетке.

04. Ветвления и циклы

Конструкция Назначение
если (условие) { … } иначе { … }
if / else 		Выбрать действия по условию. Ветку иначе можно опустить.
повтори (n) { … }
repeat		 Выполнить тело n раз. Число повторений вычисляется один раз.
пока (условие) { … }
while 		Перед каждым повторением проверять условие.
цикл (i = 0; i < n; i = i + 1) { … }
for 		Задать начальное значение, условие и изменение счётчика. Объявите i перед циклом.
прервать; / break; Выйти из ближайшего цикла.
продолжить; / continue; Перейти к следующему повторению. В цикл сначала выполняется изменение счётчика. 
Квадраты
{
    целые i;
    цикл (i = 1; i <= 5; i = i + 1) {
        если (i == 3) продолжить;
        выводстр i, " в квадрате = ", i * i;
    }
}

Конструкции можно вкладывать друг в друга. Если тело состоит из одной команды, фигурные скобки необязательны.

05. Переменные и операции

Перед использованием объявите переменную: целые n = 5;. Можно объявить несколько сразу: целые a, b;. Глобальные переменные записываются перед всеми процедурами, локальные — внутри них.

Тип Пример
целые / int целые шаги = 3;
дробные / float дробные длинаСтороны = 2.5; — дробная часть отделяется точкой.
символы / char символы буква = 'А';
логические / logical логические готово = истина; Значения: истина / true, ложь / false.
Операции Обозначения
Присваивание = или :=: n = n + 1;
Арифметика + − * / % ^. В коде минус — -; % — остаток, ^ — степень.
Сравнение == != <> < <= > >=. Равенство проверяют через ==, неравенство — через != или <>.
Логическое НЕ не, not, !
Логическое И и, and, &
Логическое ИЛИ или, or, |

При делении двух целых дробная часть отбрасывается: 7 / 2 даёт 3, а 7.0 / 2 — 3.5. Используйте скобки, чтобы явно задать порядок вычислений: (a + b) * 2.

06. Ввод и вывод

Команда ввод показывает поле в консоли. Введите значение и нажмите Enter. При вводе нескольких переменных приложение запросит каждое значение отдельно.

Команда Действие
ввод a, b; / input a, b; Прочитать значения переменных, элементов массива или целой строки.
вывод "Ответ: ", n;
print, печать 		Вывести значения без перехода на новую строку.
выводстр n; / println n; Вывести значения и перейти на новую строку.
cin >> a >> b; Альтернативная запись ввода.
cout << "Ответ: " << n;
coutln << n; 		Альтернативная запись вывода. coutln добавляет новую строку.
очистить; / clrscr; Очистить вывод программы в консоли. 
СуммаЧисел
{
    целые a, b;
    вывод "Первое число: ";
    ввод a;
    вывод "Второе число: ";
    ввод b;
    выводстр "Сумма: ", a + b;
}

Для ввода 7 и 5 результат — Сумма: 12. Пробелы между значениями не добавляются автоматически: включайте их в строку, как в примере.

Формат вывода: значение:ширина:точность. Например, выводстр pi:0:2; печатает 3.14, а выводстр 7:4; дополняет число пробелами слева до ширины 4.

07. Процедуры и функции

Первой идёт главная процедура без параметров и типа результата. Ниже можно объявлять свои процедуры и функции. Процедура выполняет действия, функция возвращает значение указанного типа. 

Основная
{
    выводстр "Квадрат числа 6: ", Квадрат(6);
    Привет();
}

целые Квадрат(целые x)
{
    возврат x * x;
}

Привет()
{
    выводстр "Готово!";
}

возврат значение; / return значение; завершает функцию. В процедуре используется возврат; без значения. Разрешены вызовы функций, объявленных ниже, и рекурсия.

Параметры передаются по значению: изменение параметра внутри процедуры не меняет исходную переменную. Это относится и к массивам.

08. Массивы и строки

Одномерный массив объявляется как целые a[5];, матрица — как целые m[2][3];. Индексы начинаются с нуля: у массива длины 5 есть элементы от a[0] до a[4]. 

МассивКвадратов
{
    целые a[5], i;
    цикл (i = 0; i < 5; i = i + 1) {
        a[i] = i * i;
        выводстр a[i];
    }
}

Строка хранится в массиве символов: символы s[40];. Ей можно присвоить текст, ввести его через ввод s; или объединить строки знаком +. Текст должен помещаться в массив. 

Строка
{
    символы s[40];
    s = "Привет" + ", Робот!";
    выводстр s;
    выводстр "Длина: ", длина(s);
}

Строки заключаются в одинарные или двойные кавычки. Для кавычек внутри текста используйте другой вид снаружи: 'Он сказал "Привет"'. Обратная косая черта — обычный символ; для переноса строки используйте выводстр.

09. Математические функции

Функции можно использовать в выражениях: дробные x = sqrt(25) + abs(-3);.

Функция Результат
pi или pi() Число π.
sqrt(x), abs(x) Квадратный корень и модуль.
trunc(x) Целая часть с отбрасыванием дробной к нулю.
round(x) Округление до ближайшего целого; при равном расстоянии — к большему числу.
sign(x) Знак числа: −1, 0 или 1.
random(), random(n) Без аргумента — число от 0 включительно до 1 исключительно. С положительным целым n — целое от 0 до n − 1.
sin(x), cos(x), tan(x) Синус, косинус, тангенс угла в радианах.
sing(x), cosg(x), tang(x) Те же функции для угла в градусах.
arcsin(x), arccos(x), arctan(x) Обратные тригонометрические функции; результат в радианах.
arcsing(x), arccosg(x), arctang(x) Обратные тригонометрические функции; результат в градусах.
arctan2(y, x), arctan2g(y, x) Угол направления на точку (x, y) с учётом четверти: в радианах или градусах.
exp(x), ln(x), lg(x) Число e в степени x, натуральный и десятичный логарифмы.
RGB(r, g, b) Числовой код цвета; каждая компонента — целое от 0 до 255. Сам по себе ничего не рисует.

10. Функции для строк

Позиции символов отсчитываются от нуля. Функции изменения строки возвращают новую строку — присвойте результат переменной.

Функция Действие
длина(s) / length(s) Число символов в строке.
фрагмент(s, i, n) / copy(s, i, n) Взять до n символов, начиная с позиции i.
позиция(часть, s) / pos(часть, s) Позиция первого вхождения; -1, если подстрока не найдена.
вставить(часть, s, i) / insert(часть, s, i) Вставить подстроку перед позицией i.
удалить(s, i, n) / delete(s, i, n) Удалить до n символов с позиции i. 
РаботаСоСтрокой
{
    символы s[40];
    s = "Робот";
    s = вставить("Привет, ", s, 0);
    выводстр s;
    выводстр фрагмент(s, 8, 5);
}

11. Поле и управление

📥 загружает лабиринт из файла .maz или .txt. Кнопка ✏️ открывает редактор стен, грядок, базы и начальной позиции Робота. Кнопка 📂 над кодом открывает примеры программ.

Символ Клетка лабиринта
. Пустая клетка.
w, W Стена.
x Грядка.
b База.
0, 2, 4, 6 Робот смотрит вверх, вправо, вниз или влево соответственно.
X, B Робот на грядке или на базе, смотрит вверх.

Каждая строка файла — ряд клеток. Не указывайте несколько начальных позиций Робота.

  • F5 — выполнить или продолжить программу.
  • F10 — выполнить один шаг.
  • Esc — остановить выполнение, в том числе ожидание ввода.
  • Кнопка «Сброс» или Ctrl + R — вернуть исходное состояние поля.

12. Возможности этой версии

Здесь работают Робот-садовник и вычислительные программы с вводом и выводом. Черепаха, Чертёжник и графический экран пока не реализованы: их команды при выполнении сообщат об ошибке.

В этой версии массив может содержать до 10 000 элементов и иметь не более двух измерений. Для защиты от бесконечного выполнения установлены пределы: 1 000 000 шагов и 256 вложенных вызовов.

Для прежних программ поддерживаются запись повтори 4 раз, условия без скобок и необязательные точки с запятой. В новых программах используйте оформление из примеров выше.
